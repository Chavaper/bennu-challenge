# Challenge Salva

Programa desarrollado para el challenge de Bennu.

## Ejecución

Para ejecutar el programa, asegúrate de tener **Docker** instalado y ejecuta:

```bash
docker container run -it --rm chavaper/challenge-salva
```

El programa se ejecutará directamente en la terminal.

### Parámetros del comando

* `-it`: permite interactuar con el programa desde la terminal.
* `--rm`: elimina automáticamente el contenedor cuando finaliza la ejecución.
* `chavaper/challenge-salva`: imagen Docker utilizada para ejecutar el programa.

## Requisitos

* Docker instalado y ejecutándose.
* Conexión a Internet la primera vez que se descargue la imagen.
