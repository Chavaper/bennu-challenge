# Challenge Salva

Programa desarrollado para el challenge de Bennu.

## Ejecución

Para ejecutar el programa, asegúrate de tener **Docker** instalado y ejecutar en cmd o bash:

```bash
docker container run -it --rm chavaper/challenge-salva
```

El programa se ejecutará directamente en la terminal.


## Requisitos

* Docker instalado y ejecutándose.
* Conexión a Internet la primera vez que se descargue la imagen.
